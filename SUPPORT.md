# Getting help

- **Something does not work:** [open a bug report](https://github.com/stephenprn/unlease/issues/new?template=bug_report.yml). It asks for your server's version (the Administration shows it), the app and how to make it happen again.
- **An idea, a question:** [open an idea](https://github.com/stephenprn/unlease/issues/new?template=feature_request.yml).
- **A vulnerability:** never in an issue: [SECURITY.md](SECURITY.md).

The documentation may already answer it: [docs/README.md](docs/README.md). Unlease has one maintainer, so an answer can take a few days.
